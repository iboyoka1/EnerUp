# EnerUp – Solar Potential for Tunisia

A Next.js 14 web application for solar roofing analysis targeted at Tunisia solar companies.

## Features

- 🌍 Address search with Google Maps integration
- ☀️ Solar potential analysis via Google Solar API
- 💰 Cost/ROI estimation with interactive sliders
- 📋 Lead capture for solar companies
- 📊 Admin dashboard with charts and lead management

## Getting Started

1. Clone the repository
2. Copy `.env.example` to `.env.local` and fill in your API keys
3. Run `npm install`
4. Run `npm run dev`

## Environment Variables

- `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` – Google Maps JavaScript API key (public)
- `GOOGLE_SOLAR_API_KEY` – Google Solar API key (server-side only)
